AODV-Inspired Low-Overhead Routing for Underwater Drone Swarms Using Acoustic Communication

Research Overview

This project investigates an AODV-inspired routing approach designed to reduce communication overhead in underwater drone swarms operating over acoustic channels.

Underwater acoustic networks present significant communication challenges, including limited bandwidth, long propagation delays, high bit error rates, and energy constraints. These characteristics complicate efficient routing, particularly in mobile underwater networks where changes in connectivity may require route recovery.

The primary goal of this project is to understand the proposed routing approach, analyze its methodology, and investigate the reproducibility of its reported performance through a systematic research workflow.
